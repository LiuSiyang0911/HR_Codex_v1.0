# HR_Codex_v1.0 中文 README 设计

## 目标

为项目编写一份面向开发维护人员的中文 `README.md`，帮助新成员快速理解项目用途、准备开发环境、完成依赖还原与编译运行，并定位主要代码模块和数据流。

## 受众

- 接手项目的 C# / WPF 开发人员
- 需要排查 UDP 通信、采集、信号处理或检测流程的维护人员
- 需要构建和发布该桌面应用的工程人员

## 文档结构

1. 项目简介：说明这是基于 WPF 的雷达数据采集、处理与检测工具。
2. 主要功能：按现有页面和代码列出连接、命令、运动控制、雷达参数、采集、处理、检测与 CSV 导出能力。
3. 技术栈：列出 .NET Framework 4.7.2、WPF、MVVM、MathNet.Numerics、ScottPlot、WPF-UI 和 UDP。
4. 开发环境：说明 Windows、Visual Studio、.NET Framework 4.7.2 Developer Pack 和 NuGet 的要求。
5. 快速开始：给出克隆、NuGet 还原、打开解决方案、选择配置和运行的步骤。
6. 项目结构：解释 `Models`、`Services`、`ViewModels`、`Views`、`Helpers`、`Themes`、`Resources` 和 `Tools/UdpDataSender` 的职责。
7. 核心架构与数据流：说明 MVVM 分层、`AppServices` 共享服务，以及 UDP 数据从接收到采集、解析、处理、检测和导出的主链路。
8. 配置与输出：记录雷达参数模型、原始数据保存和检测 CSV 默认输出目录。
9. 开发注意事项：说明旧式 `packages.config` 依赖方式、命名空间仍为 `HR_Codex_v0`、大体积 `.dat` 样例文件和构建产物忽略规则。
10. 辅助工具：介绍 `Tools/UdpDataSender` 用于本地 UDP 数据发送与联调。

## 内容边界

- 只描述当前代码和项目文件能够证实的功能，不补写未经验证的设备协议、硬件型号或性能指标。
- 不提供未经确认的默认 IP、端口和实际设备接线步骤。
- 不把 `bin` 中的历史构建产物作为推荐运行方式。
- 不声称项目已有自动化测试、持续集成或正式发布流程。

## 验收标准

- README 使用简体中文，命令和路径可直接识别。
- 新维护人员能够据此完成依赖还原、编译和启动。
- 核心目录及关键服务职责与代码一致。
- 明确指出可能影响维护的已知事项和大文件管理现状。
- Markdown 标题层级、代码块和列表格式正确，无占位符或未完成章节。
